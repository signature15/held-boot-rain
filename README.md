# held-boot-rain

## Purpose

A small Node 22 program that writes one quiet still-life sentence about rainwater held in a boot and a leaf settling on its surface.

## Run

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose a different output directory. The default is `./output`.
